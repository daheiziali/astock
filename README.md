# A股市场结构仪 Demo

这是用于展示 **A股市场结构仪** 的静态 demo 页面，方便给技术人员或协作方查看产品结构、指标口径和技术落地说明。

## 在线展示

如果 GitHub Pages 已启用，访问：

https://daheiziali.github.io/astock/

如果暂未启用 Pages，可先用 HTML 预览服务查看：

https://htmlpreview.github.io/?https://github.com/daheiziali/astock/blob/main/index.html

## 启用 GitHub Pages

进入仓库：

https://github.com/daheiziali/astock/settings/pages

选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

保存后等待 1-2 分钟，即可通过 GitHub Pages 地址访问。

## 页面内容

- 产品指标卡片
- 示例曲线展示
- 指标计算公式
- 数据源与输入字段
- 更新频率说明
- 数据处理链路
- 建议数据表
- 质量校验规则

## 说明

当前页面为静态展示版，数据为模拟值。正式产品上线前需确认数据源商用授权、申万行业成分 PIT 口径、交易所披露延迟和数据质量校验规则。
