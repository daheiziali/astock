# A股市场结构仪产品技术说明

本项目是一个 A 股客观指标 dashboard demo。产品定位为「日频客观市场状态仪表盘」，不展示具体证券买卖建议、仓位建议或收益承诺。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

## 数据更新总原则

本产品以日频客观统计指标为主。除特别标注外，指标于交易日收盘后更新；融资融券相关指标以交易所次交易日披露数据为准。盘中数据如展示，仅作为未确认估算值。

## 总览评分定义

首页总览卡中的「结构评分」为 0-100 的客观合成展示，用于概括当前市场结构指标所处位置。该分数不表示看多、看空、买入、卖出或仓位建议。

建议合成维度：

- 成交拥挤度：大盘、深市、创业板拥挤度归一化后合成。
- 杠杆参与度：融资买入/成交额归一化。
- 市场扩散度：市场宽度及行业宽度分布归一化。
- 成交活跃度：当日成交额相对中期均值归一化。

正式产品需固定权重、归一化方法和缺失值处理规则。若任一核心指标处于估算状态，总览评分也应标记为估算。

正式产品应在页面或接口中同时返回：

- `data_date`：指标对应交易日。
- `updated_at`：本系统完成计算或入库时间。
- `data_status`：`intraday_estimated`、`close_confirmed`、`next_day_disclosed`。
- `source`：行情、融资融券、行业分类等数据来源。

## 指标口径

| 指标 | 计算公式 | 样本范围 | 推荐更新频率 | 数据状态 |
|---|---|---|---|---|
| 大盘拥挤度 | 全A成交额排名前 5% 股票成交额之和 / 全A股票总成交额 | 沪深北 A 股，剔除停牌、上市未满指定交易日、成交额无效样本 | 交易日收盘后 | `close_confirmed` |
| 深市拥挤度 | 深市成交额排名前 5% 股票成交额之和 / 深市股票总成交额 | 深市主板、创业板，剔除无效样本 | 交易日收盘后 | `close_confirmed` |
| 创业板拥挤度 | 创业板成交额排名前 5% 股票成交额之和 / 创业板股票总成交额 | 创业板股票，剔除无效样本 | 交易日收盘后 | `close_confirmed` |
| 融资买入/成交额 | 沪深市场融资买入额 / 沪深市场成交额 | 沪深融资融券标的证券汇总口径 | 次交易日盘前或交易所披露落库后 | `next_day_disclosed` |
| 市场宽度 | 行业内收盘价高于所选 MA 的股票数量 / 行业内有效交易股票数量 | 申万行业及其二级行业，有效交易股票 | 交易日收盘后 | `close_confirmed` |
| 成交活跃度 | 当日全市场成交额 / 过去 N 日全市场平均成交额 | 全 A 股票成交额汇总，默认建议 N=120 | 盘中可估算，收盘后确认 | `intraday_estimated` 或 `close_confirmed` |

## 指标实现说明

### 拥挤度类指标

大盘、深市、创业板拥挤度应共用同一套算法，只改变股票池和成交额分母。

计算流程：

1. 获取目标市场全部有效股票当日成交额。
2. 按成交额从高到低排序。
3. 取成交额排名前 5% 的股票集合。
4. 计算该集合成交额之和。
5. 除以目标市场全部有效股票成交额之和。

注意事项：

- 大盘拥挤度分母为全 A 成交额。
- 深市拥挤度分母为深市成交额，包含深市主板和创业板。
- 创业板拥挤度分母为创业板总成交额。
- 三者不可混用成交额分母。
- 正式值建议只在收盘后生成；盘中版本只能标记为估算。

### 融资买入/成交额

该指标衡量融资买入交易对市场成交额的参与程度。

计算流程：

1. 获取沪深两市前一交易日融资买入额。
2. 获取同一交易日沪深市场成交额。
3. 计算融资买入额 / 市场成交额。

注意事项：

- 融资融券数据来自交易所或官方汇总披露，通常为前一交易日数据。
- 不建议展示为实时指标。
- 页面应明确标注对应交易日，而不是系统当天日期。

### 市场宽度

市场宽度用于观察行业内股票站上移动均线的比例。

计算流程：

1. 获取股票所属申万一级、二级行业。
2. 对每只有效股票计算所选 MA：MA5、MA10、MA20、MA60。
3. 判断当日收盘价是否高于所选 MA。
4. 按行业统计站上 MA 的股票数量和有效股票数量。
5. 计算行业宽度：站上 MA 股票数量 / 行业有效股票数量。
6. 市场平均可按行业等权平均或全样本股票数量加权平均，正式产品需固定并披露口径。

交互建议：

- MA 类型：MA5、MA10、MA20、MA60。
- 数据视图：原始值、变化值。
- 变化值：今日行业宽度 - 前一交易日行业宽度。
- 日期区间选择应影响风格极值面板和热力图。
- 风格极值面板只展示每个风格组内部宽度最高和最低的二级行业，不做主观判断。

### 成交活跃度

成交活跃度用于观察当日成交额相对中期成交均值的放大程度。

计算流程：

1. 获取当日全市场成交额。
2. 获取过去 N 个交易日全市场成交额。
3. 计算过去 N 日平均成交额。
4. 计算当日成交额 / 过去 N 日平均成交额。

注意事项：

- 默认建议 N=120。
- 盘中可用实时累计成交额计算估算值，但必须标注为未确认估算。
- 收盘后以最终成交额重算并覆盖正式值。

## 数据获取渠道建议

| 数据类型 | 优先渠道 | 更新特点 | 备注 |
|---|---|---|---|
| 股票日行情、成交额、收盘价 | 交易所授权行情、持牌行情供应商、正式授权数据服务商 | 日内实时或收盘后 | 用于拥挤度、市场宽度、成交活跃度 |
| 指数行情 | 交易所授权行情或指数公司授权数据 | 日内实时或收盘后 | 用于图表对照线，例如上证指数、深证成指、创业板指 |
| 融资融券数据 | 上交所、深交所官方披露或授权数据商 | 次交易日披露前一交易日数据 | 用于融资买入/成交额 |
| 行业分类 | 申万行业分类授权数据或授权数据商 | 低频变更，需定期同步 | 用于市场宽度、风格极值、行业热力图 |
| 交易日历 | 交易所交易日历或授权数据商 | 年度/临时调整 | 所有日频指标均依赖交易日历 |

官方参考：

- 上交所融资融券汇总数据：https://www.sse.com.cn/market/othersdata/margin/sum/
- 上交所股票成交概况：https://www.sse.com.cn/market/stockdata/overview/day/
- 深交所融资融券实施细则披露规则：https://docs.static.szse.cn/www/lawrules/publicadvice/W020230201595730902047.pdf
- 深市行情授权说明：https://www.szsi.cn/cpfw/fwsq/hq/yw-2.htm

## 推荐更新任务

### 收盘后任务

建议触发时间：交易日 15:30 后，等待行情源完成收盘数据落库。

任务内容：

1. 同步股票日行情、成交额、收盘价。
2. 计算大盘拥挤度、深市拥挤度、创业板拥挤度。
3. 计算市场宽度和行业热力图。
4. 计算成交活跃度正式值。
5. 写入 `close_confirmed` 状态。

### 次交易日盘前任务

建议触发时间：交易日 8:30-9:15，具体以数据源披露完成时间为准。

任务内容：

1. 同步前一交易日融资融券数据。
2. 计算融资买入/成交额。
3. 写入 `next_day_disclosed` 状态。

### 盘中估算任务

可选，不建议第一版作为核心卖点。

任务内容：

1. 获取盘中累计成交额、最新价。
2. 估算成交活跃度。
3. 可估算拥挤度，但需明确 `intraday_estimated`。
4. 不建议盘中估算融资买入/成交额。

## 合规展示原则

- 每个指标只展示客观统计结果、计算口径、样本范围、更新时间和数据状态。
- 不输出买卖建议、仓位建议、收益承诺、个股推荐。
- 对盘中估算值必须显著标注“未确认估算”。
- 对融资融券指标必须标注“以前一交易日交易所披露数据为准”。
- 正式产品需披露数据授权状态、样本剔除规则、异常数据处理规则。
